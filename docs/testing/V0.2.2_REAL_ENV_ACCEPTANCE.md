# V0.2.2 真实环境验收手册

日期：2026-11-01
适用版本：0.2.2（本文件不宣称任何一项已完成）
执行者：账号所有者本人
边界：本项目不接触 QQ 密码、不自动登录、不绕过验证码或风控、不静默安装或启动连接器。

> **验收原则：七个连接器/QQ 节点必须分别记录。** “安装器已启动”不等于“NapCat 已安装”，
> “进程已运行”不等于“WS 已连接”，“WS 已连接”不等于“QQ 身份已确认”，
> “身份已确认”不等于“真实消息已入站或出站”。任何一项没有实际证据，就保持“未执行”。

## 4. 失败与安全事件处理

- 出现验证码、登录异常、风控提示或账号警告：立即停止，不尝试绕过，交由账号所有者处理。
- 出现发送状态未知：不要手动重复点击重发；先检查 outbox 与诊断，再人工决定。
- 发现明文凭证、未授权网络请求、任意命令执行或非受管进程操作：记录证据并停止验收。
- 任何失败都保留错误码、时间和操作步骤；不要删除失败记录后再宣称通过。
