# AI 群友 · QQ 群聊 AI 管理平台

本地优先的「AI 群友」管理平台。用户使用**自己拥有并授权管理的专用 QQ 账号**，通过自行安装并登录的 OneBot 11 连接器（如 NapCat）接入，AI 只在用户明确加入白名单的群中，按保守策略参与聊天。平台提供可治理的人格成长、消息流水线、模型 Provider、预算、审计、备份和完整的中文管理控制台。

> **P0 完整 MVP + V1.3 Phase 1 增量 + 连接加固 + 阶段 2 连接器管理 + 阶段 3 模型调用 + 阶段 4 群聊治理 + 阶段 5 接入向导与诊断 + 阶段 6 安全与数据治理 + 阶段 7 扩展契约与未来接口**：Mock 闭环、OneBot 11 接入、基础人格治理、本群范围内的长期记忆检索、手动触发或群内可选开启的后台增量 AI 记忆候选提取与人工审核、群级主/备用模型绑定与受控故障回退，以及全部管理 API/页面已实现。阶段 5 新增只读接入向导（`/onboarding`）与脱敏诊断中心（`/diagnostics`）：状态从后端证据实时推导，`ready_for_replies` 仅在真实链路完成时为真；诊断使用显式 allowlist，不返回 Token、API Key、QQ 标识、群名、消息正文或路径。桌面版首次启动进入接入向导，托盘与关闭行为按实际托盘可用性展示，运行后每 12 秒探测后端 HTTP 可达性。V1.3 Phase 1 增量补齐了多模态契约与 Mock Provider、媒体后台任务队列与用量、账号/功能预算作用域、数据保留与清理（自动清理默认关闭）、聊天内第一人称 emergent 成长与自我认知触发。连接加固新增身份验证后才在线、9 项连接诊断、官方 NapCat 下载校验脚本与审计文档。阶段 2 新增受管连接器页：安装任务、显式启动官方安装器、受管进程启停、写配置前加密快照与回滚、在线诊断复用、身份确认、配置导入与桌面目录选择；所有第三方动作需本机确认词，**不静默安装/启动**。阶段 3 新增模型列表、连通性/真实生成测试、取消本地等待、安全重试、进程内 Provider 限流、测试证据持久化与 Mock/真实状态分离；真实生成失败不会回退成 Mock 成功。阶段 6 补齐安全响应头、TrustedHost 与严格 CORS、云元数据地址拒绝、清理预览与 `CLEANUP` 确认、账号/群/人格/备份删除的 `DELETE` 确认与审计、媒体引用保护、群删除后取消待发送队列、消息 CSV 导出、备份 Schema 兼容门禁与 Electron 权限边界。阶段 7 新增统一扩展契约矩阵（`GET /api/extensions/capabilities`）：聊天适配器、模型 Provider、媒体 Provider、工具与插件分别标注接口、执行方式与保证；媒体能力区分「任务队列执行」与「仅接口契约」；停用媒体 Provider 会立即取消该能力下排队与运行中的任务并丢弃迟到结果；QQ 适配器改为注册表工厂，新增适配器无需修改消息流水线；第三方插件仍只登记清单，未来运行时必须同时满足沙箱、权限清单、用户确认、签名校验、超时、资源限制、审计与即时停用八项要求。**真实 QQ 收发与真实模型 Key 仍未验证**，真实多模态、语义检索、上下文参与、定时话题、官方 QQ 机器人等属于规划能力，界面会明确标注「未配置 / 规划中 / Mock / 未验证」，不会假装可用。

> **阶段 8：Windows 安装包与发布回归（2026-11-01）**：提供 Windows x64 NSIS 安装包，内含 PyInstaller 冻结后端、受管 NapCat 安装器、前端构建产物与 Electron 运行时；普通用户无需安装 Python/Node。新增固定命令的发布流水线（`scripts/build_release.py`）、哈希清单 `release/BUILD_INFO.json`、干净环境发布冒烟（`scripts/release_smoke.py`）、安装版运行时布局与「安装版 / 源码版」诚实的运行模式显示。安装包**未签名、无自动更新**；NSIS 安装器/卸载器尚未在独立干净机器执行。**真实 QQ 端到端尚未验证，真实模型 Key 未联调，不宣称生产就绪。** 详见 [docs/RELEASE.md](docs/RELEASE.md) 与 [CHANGELOG.md](CHANGELOG.md)。

> **桌面版有两种运行方式**：安装版自带运行时，直接启动安装后的「AI 群友」，无需 Python/Node；源码版双击根目录 `start-desktop.cmd`，由本机桌面窗口补齐依赖、构建前端、生成密钥并启动后端。两者首次启动都进入接入向导，后端运行后每 12 秒探测一次 `/api/health`（1.5 秒超时，单飞）；连续 3 次失败仅把健康状态标为降级，不改变后端进程状态，外部后端永不被停止。安装包未签名且不提供自动更新。详见 [docs/DESKTOP.md](docs/DESKTOP.md) 与 [docs/RELEASE.md](docs/RELEASE.md)。

## 重要声明

- 本项目**不登录 QQ、不收集 QQ 密码、不实现验证码绕过或风控规避**。QQ 登录完全由用户在自己安装的连接器中完成。
- 非官方连接器可能存在兼容性、平台规则与账号风险。请仅使用**自己拥有、获授权管理**的账号，并从「仅观察」开始，小范围验证后再开启回复。
- 未配置真实模型时，系统只提供 Mock 模型；Mock 回复是固定模板，**不代表真实模型能力**。
- 当前版本没有真实视觉 / OCR / 语音识别 Provider。图片、语音只会以「当前未配置识别能力」的降级提示进入上下文，AI 不会真的看到或听到内容。
- 群聊内容、OCR 文本、语音转写、工具结果一律视为**不可信数据**，不会被提升为系统或管理员指令。
- 默认只允许本机管理 API。远程管理需要显式配置，详见 [SECURITY.md](docs/SECURITY.md)。

## 技术栈

- **后端**：Python 3.12+（本仓库已在 Python 3.14.5 上验证）、FastAPI、Pydantic v2、SQLAlchemy 2 async、SQLite + aiosqlite、Alembic
- **前端**：Vue 3 + TypeScript + Vite + Element Plus + Pinia + Vue Router
- **桌面壳**：Electron 45（独立 `desktop/` 包；窗口加载本机 `http://127.0.0.1:<port>`，保持 API/SSE 同源）
- **发行**：PyInstaller（冻结后端与 NapCat 安装器）+ electron-builder / NSIS（Windows x64 安装包）；未签名
- **实时**：SSE（`/api/events/stream`）
- **安全**：Fernet 应用层加密、API 密钥掩码、日志脱敏、本机优先的管理边界、TrustedHost/CORS 白名单、CSP 与安全响应头、sandbox + contextIsolation + 最小 IPC + Electron 权限拒绝
- **质量**：pytest、ruff、mypy、vue-tsc、Vitest、`node:test`、Electron 截图冒烟、冻结运行时发布冒烟

## 接入真实 QQ（OneBot 11 / NapCat）

### 风险提示

请只使用自己拥有并获授权管理的专用账号。非官方连接器存在协议兼容、平台规则与封号风险；本软件不提供验证码绕过、设备指纹伪装、批量养号、自动加群/加好友、广告群发或限流规避。遇到验证码、风控或账号异常提示时，立即**暂停平台**并停止连接器，由账号所有者自行处理。

### 步骤

推荐使用控制台「连接器」受管页（仅本机可访问）。平台不会在后台静默执行第三方程序，
每个动作都需要输入确认词。完整说明见 [docs/CONNECTOR.md](docs/CONNECTOR.md)。

1. 打开「连接器」，可先点「选择连接器目录」（桌面版）指定受管根目录。默认
   `<仓库根>/connectors/napcat/`；改动目录后需重启后端。
2. 查询版本 → 输入 `INSTALL` → 等待下载/校验/解压任务完成。此时仅是
   「安装包已解压」，不是已安装。任务可取消；后端重启会把未完成任务标为中断。
3. 点击「运行安装器」并输入 `RUN INSTALLER`。官方安装器是交互式第三方 GUI，需由你
   自行完成；平台不代替操作、不提权，也不自动登录。完成后点「重新扫描」。
4. 输入 `START NAPCAT` 启动受管连接器，自行在 NapCat 中登录专用 QQ。页面最多显示
   「运行中 · 登录未确认（推断）」，不代表已登录。
5. 停止进程（`STOP NAPCAT`）后，打开配置预览并输入 `WRITE CONFIG`。平台会自动选择
   回环端口与随机 Token、先加密快照、原子写入，并创建 `auto_connect=false` 的实例。
   失败会自动恢复快照和旧 Token；`RESTORE CONFIG` 可回滚。
6. 重新启动并连接实例，执行「测试并诊断」。在线实例会复用现有适配器，不会建立第二
   条诊断连接；未在线时临时建连并会提示单连接限制。
7. 输入 `CONFIRM IDENTITY` 确认在线 QQ 身份，然后**导入群列表**（必须再次填写同一
   QQ 号）。导入的群默认关闭 AI 回复，请先保持「仅观察」。
8. 在「模型 API」填写真实的 OpenAI 兼容接口或 Anthropic 原生接口并点击 **测试连接**；
   测试错误会区分认证、网络、模型不存在、额度不足和超时。

**手动兜底**：如果安装到受管目录之外，或用的是未知版本，可点「配置导入」读取 NapCat
的 `onebot11*.json`（输入 `IMPORT CONFIG`，不写外部文件），或进入「QQ 接入」高级手动
设置填写 WS/HTTP 地址与 Token。脚本仍可用于下载/校验/解压：

```powershell
backend\.venv\Scripts\python.exe scripts\install_napcat.py --dry-run  # 只查看版本/哈希
backend\.venv\Scripts\python.exe scripts\install_napcat.py            # 下载、校验、解压
```

脚本不会自动运行安装器或登录 QQ；手工 `--launch` 需交互式终端输入 `LAUNCH`。

### 字段与行为

- 连接器状态、心跳、最后收发时间与错误码来自当前进程；后端重启后需重新连接，受管 NapCat 也不会被自动停止或重新接管。
- 受管安装、进程、配置与诊断只通过 `/api/connectors/*` 的本机页面操作；每个写动作都需确认词并写审计。安装包已解压、进程存活或 WS 已连接均不等于真实收发已验证。
- 收到的事件会先经过去重、自身消息过滤和白名单检查；未通过硬规则的消息不会触发模型调用。
- 发送状态未知（如网络超时）的队列消息标记为 `unknown`，**不会自动重发**，避免重复发送。
- 连续发送失败达到阈值会自动暂停该群并记录事件。
- 当前版本不下载或转存真实图片/语音，也不下载文件；媒体段只保留安全元数据与降级提示。

## 群白名单与回复策略

- **白名单默认空**：不导入或启用任何群，AI 不会回复。
- **新建与导入的群默认「观察」**：只记录和做安全判断，不生成回复；既有群的回复模式不会被静默迁移。演示群使用显式的「仅 @ 回复」预设。
- **仅 @ 回复**：被 @ 或回复机器人消息时生成回复。
- **手动确认**：触发条件与「仅 @ 回复」相同，但生成后只进入待审核队列，必须在「消息与用量」中人工通过或拒绝，绝不自动发送。
- **自动回复**：对所有通过硬规则的消息生成回复，仍受限频、预算与输出审查约束。
- **关键词触发（高级）**：命中群配置关键词，或被 @ / 回复机器人时生成回复；「上下文参与」与「定时话题」仍为规划中，当前版本会拒绝保存这些模式。
- 限频同时包含群级与每成员每小时/每日回复上限；每个人限频按已发送或状态未知的 AI 回复统计，命令回复与待审核草稿不占额度。
- 发送前会重新检查全局暂停、群启用、安静时段与成员静音；群级可覆盖回复字数上限与上下文消息条数。
- 输出会检查疑似密码、验证码、证件号、银行卡与 API Key，并清洗长度、全员 @ 与控制字符；命令回复和人工批准同样经过检查。
- 「同一发送者 60 秒内至少 4 条完全相同的非空文本」为本机重复刷屏启发式，重启后清零，不能识别所有第三方机器人。
- 全局紧急暂停优先于一切：不生成发送，也不派发待审队列之外的自动发送。
- 工具默认在群内禁用；不存在任意 Shell、PowerShell、文件读写或任意 HTTP 请求工具。

## 人格治理

- **用户编写（authored）**：由用户定义自我描述与设定字段。
- **模板（template）**：选择内置模板作为起点。
- **空白自成长（emergent）**：初始无性格、无背景；AI 只能提出结构化人格提案，经治理服务校验证据、置信度、范围和锁定字段后，按「自动 / 人工审核 / 暂停」处理。
- 成长提示词以第一人称让“人格自身”反思当前设定与刚发生的互动，输出结构化提案与自然语言变化摘要 `diff_summary`，不保存分析步骤或思维链。成长在回复完成后异步执行，不会阻塞聊天。
- 用户问“你是谁 / 你的人设 / 介绍一下你自己”时，会触发一次 `self_inquiry` 成长分析；它只豁免成长最小间隔，**不豁免**证据数量、会话数、置信度、锁定字段与范围治理。同一人格+群并发成长会合并，不重复排队。
- 默认证据门槛：至少 2 个不同会话、3 次一致证据；单条消息不能改变人格。
- 每次变更生成版本与变更事件，可回滚；锁定字段、系统安全规则、群规和工具权限不可被成长覆盖。成长提案命中“忽略/绕过/关闭/修改安全规则、系统提示、白名单、管理员权限、预算、群规或工具权限”等规则改写时会被拒绝并记录。
- 保存人格前会先调用预览接口做纯投影，展示字段与特征级差异；确认后才写入，预览不会新增版本或审计。版本历史可查看脱敏快照与相对当前状态的差异后再回滚。
- 成长候选只保存提案与证据，不会提前物化为人格特征；批准时才应用。待审核提案展示旧/新状态、影响范围、锁定跳过项和绑定群范围内的证据预览，不保存思维链。
- 跨群学习默认关闭；群消息不得提升为系统指令。
- 人格工作台中的「测试对话」只做 dry-run，不发送、不写消息日志。

## 备份与恢复

- 通过「系统设置 → 备份」或 `POST /api/backups` 创建一致性 SQLite 备份。
- 每个备份有清单、SHA-256、表计数和 SQLite 完整性校验。
- 恢复预览同时显示备份/当前程序的 Schema 状态与版本。只有备份与当前代码的 Alembic head 不一致时才标记 `incompatible` 并禁止恢复；缺少版本信息时标记 `unknown`、显示警告后仍允许恢复。
- 恢复前必须：全局暂停 → 校验备份 → 阅读预览 → 输入 `RESTORE`。系统会在 Schema 兼容检查通过后自动创建安全备份并断开所有连接器；不兼容时不会创建安全备份、不会改动数据库。
- 删除备份需要输入 `DELETE` 并写审计。
- 备份**不包含**媒体文件、日志和 `CREDENTIAL_ENCRYPTION_KEY`。恢复后需使用同一加密密钥，否则旧 Token/API Key 无法解密。
- 命令行备份（后端未运行时自动使用 SQLite 在线备份）：

```powershell
.\scripts\backup.ps1 -Note "升级前"
# 或显式离线
.\scripts\backup.ps1 -Offline
```

离线备份不会出现在控制台备份列表与审计中，正式恢复仍建议使用控制台流程。

## 排错

| 现象 | 处理 |
| --- | --- |
| 打开 `:8000` 显示「前端尚未构建」 | `cd frontend; npm run build`，或开发时使用 Vite `:5173` |
| 保存 Provider 报 `CREDENTIAL_KEY_MISSING` | 运行 `python scripts/gen_keys.py --write` 并重启后端；不要用错误格式的 Fernet 密钥 |
| 远程访问返回 403 / 401 | 默认只允许本机。确需远程时设置 `ALLOW_REMOTE_ADMIN=true`、强 `ADMIN_API_TOKEN`，并通过受保护的反向代理（HTTPS）访问 |
| NapCat 连接失败 | 检查 WS/HTTP 端口、Token、连接器是否启动；公网地址需显式允许；查看「QQ 接入」中的状态 JSON 与错误码 |
| 测试模型报认证/模型/额度错误 | 在「模型 API」点击测试，按返回的 `error_code` 分类排查；Mock 模型无需 Key |
| 401/403 之外的端口冲突 | 修改 `APP_PORT` 或 Vite 端口，并同步代理配置 |
| 回复始终被拦截 | 查看「消息与用量」的拦截原因：白名单、观察模式、仅 @、安静时段、群级/每成员限频、全局暂停、预算、模型未配置、疑似敏感输出 |
| 手动确认模式下没有自动回复 | 这是预期行为；到「消息与用量 → 发送队列」筛选「待确认发送」，编辑后通过或拒绝 |
| 备份恢复后连接器离线 | 这是预期行为；确认配置后重新连接。旧凭证还需要原加密密钥 |
| Windows 中文乱码 | 使用 Windows Terminal；脚本已设置 `PYTHONUTF8=1`，Python 输出显式使用 UTF-8 |
| 前端构建提示 chunk 过大 | Element Plus 整体打包导致，仅警告，不影响功能 |
| 桌面版提示 Electron 下载失败 | 设置 `ELECTRON_MIRROR` 镜像后重试，或检查网络/代理；详见 [DESKTOP.md](docs/DESKTOP.md) |
| 桌面版启动向导失败 | 查看控制页日志；常见原因是 Python/Node 版本、网络、`.env` 密钥无效或端口占用。已完成步骤可安全重试 |

## 安全与隐私

- 群消息默认保存在本机 SQLite。启用真实模型后，经过筛选的上下文会发送给你配置的模型服务；请自行评估服务条款与数据合规。
- Token / API Key 以 Fernet 密文存储，接口只返回掩码，日志做防御性脱敏。
- 管理 API 默认仅本机，并通过 TrustedHost 与 CORS 白名单限制来源；HTML 响应带 CSP 与安全头。所有管理写操作尽量写审计；删除与清理需要服务端确认词。
- Provider Base URL 拒绝云元数据与链路本地地址，但不解析 DNS；自定义域名仍可能在解析后被指向内网，请只配置可信模型服务。适配器不跟随重定向。
- 数据保留期限可在「系统设置」配置（日志 30 天 / 消息 90 天 / 媒体 30 天为默认值；记忆保留天数默认 `0` 表示不自动删除）。**自动清理默认关闭**，需管理员显式开启；手动清理始终可用并写审计。自动清理删除超过期限的消息、媒体、转写、媒体任务、`app.log.*` 轮转日志、人格证据/版本快照中的证据引用、记忆来源 ID 与超期未固定记忆；不会改动当前 `app.log`，也不会调用模型或发送消息。全局暂停不阻止本地清理。
- 记忆导出使用当前筛选条件，CSV 带 UTF-8 BOM 并做公式注入防护；默认排除敏感记忆，只有在界面显式勾选后才包含，导出动作写审计但不记录记忆正文。手动记忆清理支持「仅统计」预览，固定记忆不会被删除。
- 不要在 Issue、截图或日志中公开 `.env`、Token、API Key 或真实群成员信息。

完整安全说明与事件响应清单见 [docs/SECURITY.md](docs/SECURITY.md)。

## 已知限制

- **真实 QQ 未验证**：没有真实 NapCat 登录环境；OneBot 11 仅通过进程内假服务器与协议测试验证。连接诊断通过只代表 WS、鉴权、身份与动作证据，不证明真实群消息收发成功。验收清单见 [docs/CONNECTOR.md](docs/CONNECTOR.md)。
- 没有真实模型 Key；OpenAI 兼容与 Anthropic 原生适配器均只用 MockTransport 验证请求映射、错误分类、重试与模型列表，未调用真实服务。真实 Key 验收需用户自行完成：连通性、真实生成、错误场景、取消、预算与清除 Key 后重启；完成前不得把“真实模型已验证”写入说明。
- 官方 NapCat OneKey 包已在本轮实际下载、校验并解压到 `connectors/napcat/v4.18.42/`，但**没有运行安装器、没有登录 QQ**，因此安装器内部行为与真实连接仍未验证。
- 阶段 2 的连接器安装任务、进程启停、安装器启动与配置写入只用临时目录、假进程和假 I/O 验证；**没有对真实 NapCat 执行**。自动写配置仅覆盖文档验证的 `v4.18.42`；其他版本只能检测、手动配置或导入。
- 平台不自动更新、不自动卸载、不接管外部安装或后端重启前启动的进程；停止按钮只结束本会话仍跟踪的进程树，未跟踪时请手动关闭。NapCat 配置文件中的 Token 由第三方明文保存，平台无法保证其文件权限。
- 全局紧急暂停会阻止启动连接器、运行安装器与写配置；下载任务的取消与重试仍需用户确认。
- 「上下文参与」与「定时话题」为规划能力；当前创建群时提交 `context` 会被拒绝。
- 真实图片/语音不会下载或识别；媒体任务队列、Provider 与用量记录已实现，但 Provider 均为 Mock，界面已如实标注。图片/语音片段在流水线中只入队，不会阻塞 QQ 事件；后台 worker 仅在应用内处理 Mock 任务。Reranker、视频理解与真实 OCR/ASR/TTS/Embedding 仅契约和 Mock，未接入业务管线。
- 保留清理提供只读预览，但预览与执行之间可能有新消息写入，实际删除数以运行摘要为准；分批上限会截断并标记 `truncated`。清理不处理 outbox、审计、备份与当前 `app.log`；消息清理只擦除记忆/候选中的来源消息 ID，不改写记忆正文，只有手动或自动记忆保留清理才会删除未固定记忆正文。删除账号/群不可撤销；群删除保留历史消息但解除群关联。
- 长期记忆支持手动录入、手动触发或群级后台增量 AI 候选提取（必须人工审核）与本群范围内的关键词/二元词检索；后台提取默认关闭、按水位线增量扫描、全局暂停时停止。没有摘要压缩或向量语义检索。Mock 模型生成的候选仅用于演示，不应作为真实记忆长期保留。
- 每人限频按 outbox 中 `sent`/`unknown` 的 AI 回复统计，待审核草稿在批准并发送后才计入；历史记录缺少来源成员时不会归属到具体成员，成员额度可能暂时偏宽，群级限制仍然生效。重复刷屏保护是本进程内启发式，重启清零。
- 「手动确认」只约束 AI 回复；管理员命令仍即时执行，但同样经过输出清洗与敏感内容检查。
- 模型路由目前只支持按群绑定主/备用 Provider，不支持按功能拆分模型，也没有基于成本、延迟或健康度的自动路由；回退仅在显式配置备用模型时发生。
- 费用是本地估算：只有你填写 Provider 单价、且服务返回完整 Token 用量后才会计算，且不是服务商账单；未配置单价或用量缺失的调用标记为不可计价，不会显示为 0。费用预算启用时，未配置单价的非 Mock Provider 会被阻断。若 Provider 不返回 Token 用量，该次调用无法计入费用上限，请改用会返回 `usage` 的接口。
- 用量趋势按配置时区（默认 `Asia/Shanghai`）在应用层分桶，不是服务商账单；未知费用保持为空。预算告警基于已记录的本地用量，同一策略、同一统计周期、同一级别最多记录一次；告警不会自动解除或执行额外动作，达到上限时仍由预算检查阻断调用。CSV 只导出模型调用元数据（时间、Provider、模型、Token、估算费用、状态等），不含消息正文、提示词、API Key 或任何凭证。
- Windows 安装版已构建并完成隔离冒烟，**但安装包未签名、无自动更新，NSIS 安装器/卸载器尚未在独立干净机器执行**；“干净环境冒烟”使用隔离的 `win-unpacked`、临时 `userData`/数据目录和系统级 `PATH`，不等于在全新 Windows 上安装。安装版不含代码签名，SmartScreen 可能提示未知发布者。
- 源码桌面版仍需本机 Python 3.12+ / Node.js 20+，升级前端代码后需重新构建。两种桌面方式都不会绕过既有安全边界；外部启动的本项目后端只会被连接、不会被桌面版停止。
- 升级安装版前必须创建控制台备份并复制整个 `%APPDATA%\ai-group-friend-desktop`。没有自动降级；用旧版本打开已迁移的新数据库不受支持。卸载默认保留用户数据，彻底删除需手工清理并承担丢失 `CREDENTIAL_ENCRYPTION_KEY` 后旧凭证不可解密的后果。
- 定时话题、评测回放、插件执行、多账号、MCP 等仍为规划能力。
- SQLite 适合单机小规模使用；高并发或多实例部署不在当前范围。
- 非官方连接器的兼容性与账号风险由用户自行评估。
